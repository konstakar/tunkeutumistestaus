# x) Tiivistä
- Mastering Metasploit
  - metasploit on penetraatiotestaustyökalu, jolla voidaan etsiä ja hyödyntää tietoturva-aukkoja.
  - nmap = sillä voidaan skannata kohdetta ja selvittaa kohteen avoimet portit ja käytössä olevat palvelut.
  - metasploitin exploit hyödyntää havoittuvuuksia ja payload määrittelee mitä hyökkäyksen jälkeen tehdään
  - workspace = penetraatiotestien tulokset voidaan erottaa toisistaan
  - post-exploitation vaiheessa hyökkääjä saattaa kerätä dataa kohdekoneesta, esim. käyttäjät, prosessit, verkkoyhteydet
  Lähde: https://learning.oreilly.com/library/view/mastering-metasploit/9781838980078/B15076_01_Final_ASB_ePub.xhtml#_idParaDest-31

- Mitä "nmap -sn" tekee?
  - suorittaa host discovery skannauksen = selvittää, mitkä annetulla IP-alueella olevista laitteista ovat aktiivisia.
  - ei suorita porttiskannausta
  - -sn estää porttiskannauksen host discovery-vaiheen jälkeen ja näyttää laitteet, jotka vastaavat discoveryyn
  - ennen nimellä "ping scan"
  - luotettava, koska etsin nmapin viralliselta sivustolta.
 Lähde: https://nmap.org/book/man-host-discovery.html
